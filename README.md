# Rhythm Sync Teacher

Браузерное MVP для тренировки танцевального ритма: метроном, эталонный человечек и камера с распознаванием топа ноги.

- [Архитектура](docs/architecture.md)

## Запуск

```bash
npm install
npm run dev
```

Откройте URL из терминала (обычно `http://localhost:5173`) в Chrome или Edge. Разрешите доступ к камере.

```bash
npm test
npm run build
```

## Как пользоваться

1. Встаньте так, чтобы в кадре было видно тело целиком и ноги (или включите **Только ноги**).
2. Выберите BPM, при необходимости окно попадания и компенсацию задержки камеры.
3. Нажмите **Старт** — зазвучит метроном, учитель начнёт топать.
4. Топайте ногой в такт. Оранжевый индикатор — бит, бирюзовый — топ распознан камерой.
5. **Сначала** обнуляет статистику и ленту результатов.

## Стек

- Vite + React + TypeScript
- Web Audio API (метроном)
- MediaPipe Pose Landmarker (скелет и детекция топа)
- Vitest (unit-тесты ядра)
