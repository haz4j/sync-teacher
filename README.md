# Rhythm Sync Teacher

Браузерное MVP для тренировки танцевального ритма: метроном, эталонный человечек и камера с распознаванием топа ноги.

## Запуск

```bash
npm install
npm run dev
```

Откройте URL из терминала (обычно `http://localhost:5173`) в Chrome или Edge. Разрешите доступ к камере.

## Как пользоваться

1. Встаньте так, чтобы в кадре было видно тело целиком и ноги.
2. Выберите BPM (60–140).
3. Нажмите **Старт** — зазвучит метроном, учитель начнёт топать.
4. Топайте ногой в такт. Попадания и точность отображаются сверху.

## Стек

- Vite + React + TypeScript
- Web Audio API (метроном)
- MediaPipe Pose Landmarker (скелет и детекция топа)
