# Rhythm Sync Teacher — ТЗ v2

## Продукт

Браузерное приложение для тренировки танцевального ритма: пользователь топает ногой в такт метроному, камера распознаёт движение, система считает попадания.

**Пользователь:** человек, который учится чувствовать ритм сам (ученик / самотренировка). Тренер и групповые занятия — вне текущего релиза.

**Платформа:** десктопный браузер (Chrome / Edge). Камера обязательна.

## Сценарий занятия

1. Открыть приложение, разрешить камеру.
2. Выбрать BPM (20–140).
3. Нажать **Старт** — метроном кликает, учитель топает, идёт скоринг.
4. Топать ногой в такт; смотреть accuracy, попадания/промахи и подсказку раньше/позже.
5. При необходимости нажать **Сначала** — обнулить статистику без обязательной остановки.
6. Нажать **Стоп** — занятие заканчивается.

## Уже готово (MVP baseline)

- Метроном на Web Audio с настраиваемым BPM.
- Stick-figure учитель, топающий по битам.
- Веб-камера + MediaPipe Pose + overlay скелета.
- Детекция топа по лодыжкам/стопе.
- Скоринг hit/miss с компенсацией задержки камеры.
- Accuracy, мгновенный feedback, вспышка кадра при распознанном топе.
- Кнопка **Сначала** (сброс статистики).
- Детекция топа работает и при кадре только с ногами (от пояса вниз), без отдельного режима.

## Ближайший релиз (не больше трёх фич)

1. **Настройки точности в UI** — ползунки окна попадания (мс) и компенсации latency камеры (мс).
2. **Расширенная обратная связь** — раньше/позже на попадании + лента последних 8 результатов (hit/miss).
3. **Калибровочная подсказка** — короткий текст/индикатор «топ распознан» vs «в ритм», чтобы отличать детект от скоринга.

Следующее упражнение (не топот) — **не** в этом релизе.

## Вне scope (пока)

- Загрузка музыки / beat detection.
- Аккаунты, облако, история занятий на сервере.
- Мобильное нативное приложение.
- Несколько упражнений / хореография.
- Бэкенд любого вида.

## Критерии «готово» для релиза

- При BPM 60–80 пользователь видит вспышку кадра на топ и рост accuracy при попадании в бит.
- Окно попадания и latency можно изменить без перезагрузки; новые значения применяются к следующим битам.
- Лента последних результатов обновляется в реальном времени.
- **Сначала** обнуляет hits/misses/accuracy/ленту.
- Unit-тесты на `scorer` и `stompDetector` зелёные (`npm test`).
- UI на русском.

## Нефункциональные требования

- Всё локально в браузере, без сервера.
- Логика ритма в `src/lib/`, UI только отображает.
- Не ломать работу без GPU-делегата MediaPipe (fallback допустим на уровне уже существующей инициализации).
