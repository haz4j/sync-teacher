# Приёмка (acceptance)

Чеклист для ручной проверки MVP и релиза v2. Отмечайте результат при прогоне.

Окружение: Chrome или Edge, десктоп, веб-камера, `npm run dev`.

## MVP baseline


| #   | Проверка           | Ожидание                                                    | Статус |
| --- | ------------------ | ----------------------------------------------------------- | ------ |
| A1  | Открыть приложение | Загружается UI, запрос камеры                               | 1      |
| A2  | Разрешить камеру   | Видео справа, без ошибки модели                             | 1      |
| A3  | BPM 20–140         | Значение меняется на контроле                               | 1      |
| A4  | Старт              | Слышны клики метронома                                      | 1      |
| A5  | Учитель            | Человечек топает в такт, пульс бита мигает                  | 1      |
| A6  | Скелет             | Overlay следует за телом/ногами                             | 1      |
| A7  | Топ ногой          | Бирюзовая вспышка рамки камеры («топ распознан»)            |        |
| A8  | Попадание в бит    | «В ритм!» / accuracy растёт, hits++                         |        |
| A9  | Промах             | «Мимо», misses++                                            |        |
| A10 | Стоп               | Метроном и скоринг останавливаются                          |        |
| A11 | Сначала            | hits/misses/accuracy = 0 (можно на паузе или во время игры) |        |
| A12 | Кадр только с ногами | При съёмке от пояса вниз топ всё ещё распознаётся (вспышка / hits) | |




## Релиз v2


| #   | Проверка                   | Ожидание                                                            | Статус |
| --- | -------------------------- | ------------------------------------------------------------------- | ------ |
| B1  | Ползунок окна попадания    | Меняет допуск; после изменения новые биты судятся по новому окну    |        |
| B2  | Ползунок latency           | Меняет компенсацию; влияет на «раньше/позже»                        |        |
| B3  | Offset на hit              | Показывается «точно» / «N мс раньше» / «N мс позже»                 |        |
| B4  | Лента результатов          | Последние до 8 hit/miss обновляются                                 |        |
| B5  | Сначала очищает ленту      | История пустая после сброса                                         |        |
| B6  | Индикатор детекта vs ритма | Вспышка кадра ≠ обязательный hit; hit только при совпадении с битом |        |

## Definition of Done для фичи

Фича готова, если:

1. Соответствует пункту в [spec.md](./spec.md).
2. Затронутые пункты acceptance выше проходят вручную.
3. Unit-тесты ядра зелёные (если менялся `src/lib`).
4. Изменения закоммичены и запушены в `origin`.
